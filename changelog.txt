Changelog

1. v13 redesign: new sidebar UI (CustomTkinter). Launch straight into a
   character picker (newest save first, with name/mode/level/played-ago),
   pick a save, and edit across six pages — Overview, Character, Skills,
   Inventory, Storage, Unlocks — each with icons for every item. One Save
   button writes the whole file at once and keeps timestamped .bak- backups
   (5 kept), replacing the old tabbed live-JSON-preview editor.
2. Updated to the Umbral Sands game version (items, recipes, buildings, mounts, and save layout refreshed).
3. Added one-click unlockers for recipes, buildings, mounts, picked-up items, and all 18 Sanguine Urns.
4. Added per-expansion loadout templates — apply a region/class best-in-slot gear & storage kit in one click.
5. Added name-based search & filtering across all item lists.
6. Packaged as a single Windows .exe (no Python needed) with a proper window/taskbar icon.
7. Redesigned the About screen (icon, description, credits) and made it open on first launch.
8. Fixed the standalone exe showing "Coming soon..." on every page (the editor pages were missing from the compiled build).
9. Restored the full About content: app icon, description, and the credits — originally created by TatsumaYakoshi, continued & maintained by TailwindDev, with a shout out to Elleandria.
10. Extended item-icon coverage from 754 to 1,384 of 1,385 items — icons are now read directly from the game files, so every real item shows its proper icon.
11. Mount unlocker now covers all 21 mounts (5 Flying Carpets + 16 Terrorbirds, verified against the game files) — two carpet variants were previously missing.
12. Inventory & Storage grids restyled to match the in-game look: icons fill the slots, stack counts overlay the corner, the Bag shows its numbered hotbar row (slots 1-8) separately, and hovering a slot shows the item name in the status bar.
